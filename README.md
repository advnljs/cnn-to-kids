# 🎨 人脸识别小课堂 - CNN 可视化教学工具

一个专为小学生设计的交互式 Web 应用，通过生动的可视化方式讲解卷积神经网络（CNN）如何识别人脸表情。

## 🌟 项目特色

- **零数学公式**：用"特征探测器"、"信息压缩"等直观概念代替复杂的数学术语
- **完整自洽**：从原理到实现形成完整的知识体系，不只是简单比喻
- **交互式学习**：学生可以画图或生成表情，实时看到 CNN 的工作过程
- **🎓 训练模式**（NEW!）：让学生亲手训练AI模型
  - 绘制自己的表情样本并标注
  - 实时看到训练样本数量增长
  - 使用自己训练的模型进行识别
  - 理解"机器学习"的本质：从数据中学习
  - 训练数据自动保存，刷新页面不丢失
- **🎬 实时动画展示**：卷积核和池化窗口的扫描过程完全可视化
  - 红色高亮框显示当前扫描位置
  - 实时生成输出特征图
  - 逐格扫描，让学生清楚看到每一步计算
- **🌈 彩色热力图**：高级特征用彩色显示，更加直观
  - 蓝色 = 弱特征（不重要）
  - 绿色 = 中等特征
  - 黄色 = 强特征（重要）
  - 红色 = 极强特征（非常重要）
- **🎯 智能分类**：支持两种识别方式
  - **KNN算法**：使用训练样本进行识别（训练模式优先）
  - **规则分类**：基于特征分布的智能判断（无训练数据时使用）
- **分步可视化**：每一步都有清晰的网格展示和流畅动画
- **深入浅出**：既有趣味性，又保持了一定的技术深度

## 🎯 教学目标

通过这个工具，小学生能够理解：

1. **特征探测器**：计算机如何用不同的"眼镜"寻找特定图案（横线、竖线、边缘）
2. **卷积操作**：用 3×3 的小窗口在图像上滑动，提取特征
3. **激活函数**：保留重要信息，忽略不重要的信号
4. **池化操作**：通过"取最强信号"压缩信息
5. **分层学习**：从简单线条到复杂特征的渐进过程
6. **分类判断**：如何综合所有特征做出最终判断

## 🧠 核心概念解释

### 特征探测器（卷积核）

特征探测器就像一副特殊的眼镜，每个探测器只能看到特定的图案：

```
横线探测器:        竖线探测器:        边缘探测器:
[-1, -1, -1]      [-1,  2, -1]      [-1, -1, -1]
[ 2,  2,  2]      [-1,  2, -1]      [-1,  8, -1]
[-1, -1, -1]      [-1,  2, -1]      [-1, -1, -1]
```

### 卷积操作

用 3×3 的小窗口在图像上滑动，计算窗口内的图案与探测器的"匹配度"：

- 匹配度高 → 找到了这个特征！
- 匹配度低 → 这里没有这个特征

### 池化操作（Max Pooling）

把 2×2 的格子合并成 1 个格子，只保留最强的信号：

```
输入:           输出:
[8, 3]  [5, 2]
[1, 4]  [9, 6]  →  [8, 9]
[7, 2]  [3, 1]     [7, 4]
[5, 4]  [2, 0]
```

### 分层学习

```
第一层：提取简单特征（横线、竖线、边缘）
  ↓
第二层：压缩信息（池化）【热力图显示特征强度】
  ↓
第三层：分析特征分布，识别表情（笑脸、哭脸）
```

### 热力图可视化

为什么要用彩色热力图？

- **问题**：池化后的特征图较小，用灰度图不容易看出哪里是重要特征
- **解决**：用颜色表示特征强度
  - 🔵 **蓝色**：特征很弱（0-25%），不重要
  - 🟢 **绿色**：中等特征（25-50%），有一些信息
  - 🟡 **黄色**：较强特征（50-75%），值得注意
  - 🔴 **红色**：极强特征（75-100%），非常重要！

**例如**：识别笑脸时，横线探测器的热力图在嘴巴上方区域会显示为**红色或黄色**，说明那里发现了强烈的横线特征（嘴角向上）！

### 智能分类算法

计算机如何判断是笑脸还是哭脸？

**核心思路**：分析横线探测器在嘴巴区域的上下分布

1. **确定嘴巴区域**：图像的 35%-65% 位置（中部偏下）

2. **分析特征分布**：
   - 统计嘴巴区域上半部的横线特征强度
   - 统计嘴巴区域下半部的横线特征强度
   - 计算上下比例

3. **判断规则**：
   - **上半部特征强** (比例 > 1.3) → 笑脸 😊
     - 因为笑脸的嘴角向上，横线主要在上方
   - **下半部特征强** (比例 < 0.7) → 哭脸 😢
     - 因为哭脸的嘴角向下，横线主要在下方
   - **不明显**（0.7-1.3之间）→ 使用原始像素分布辅助判断

4. **置信度计算**：
   - 基础置信度：70%
   - 根据特征比例差异调整
   - 最高不超过 95%

**简洁有效！** 主要依靠横线探测器，辅以原始像素分析。

### 常见问题解答

**Q: 为什么要用网格？**
A: 计算机不能像人一样直接"看"图像，需要把图像转换成数字。每个格子就是一个数字！

**Q: 为什么要分这么多步？**
A: 就像搭积木，要先找到小块，再组成大块，最后搭成完整的作品。

**Q: 真实的人脸识别是这样的吗？**
A: 原理是一样的！但真实系统有更多层、更复杂的探测器，可以识别更多细节。

## 🔧 技术实现

### 技术栈

- **纯前端实现**：HTML5 + CSS3 + JavaScript (ES6+)
- **Canvas API**：用于绘图和图像处理
- **无依赖**：不需要任何外部库

### 核心算法

1. **图像灰度化与下采样**：
   - RGB → 灰度值转换
   - **区域平均采样**（Area Averaging）：280×280 → 28×28
   - 对源图像10×10区域内所有像素取平均值
   - 避免最近邻采样导致的线条丢失和锯齿
   - 显著提高细节保留能力
2. **卷积运算**：实现了标准的 2D 卷积操作
3. **ReLU 激活**：max(0, x)
4. **最大池化**：2×2 窗口取最大值
5. **🎓 KNN 分类器**（训练模式）：
   - 提取池化后的特征向量（3个13×13矩阵展平 = 507维）
   - 计算欧氏距离找到K个最近邻（默认K=3）
   - 多数投票决定分类结果
   - 儿童友好解释："找到最像的训练样本"
6. **🎯 规则分类器**（无训练数据时）：
   - 基于横线探测器的特征分布
   - 嘴巴区域（35%-65%）上下比例分析
   - 辅助原始像素判断
   - 置信度计算（70-95%）
7. **🎬 动画系统**：
   - 逐步卷积动画：实时显示卷积核扫描位置
   - 逐步池化动画：实时显示池化窗口移动
   - 渐进式特征图生成：边扫描边显示结果
8. **🌈 热力图渲染**：
   - 彩色梯度映射：值 → RGB 颜色
   - 分段线性插值：蓝→绿→黄→红
   - 适用于高级特征的可视化
9. **💾 训练数据管理**：
   - localStorage 持久化存储
   - 样本缩略图显示
   - 增删改查完整操作

### 图像采样技术详解

**问题**：画布280×280缩放到28×28时，如何避免信息丢失？

**方案对比**：

| 采样方法 | 原理 | 优点 | 缺点 |
|---------|------|------|------|
| **最近邻采样** | 只取一个像素点 | 速度快，实现简单 | ❌ 细线条会消失<br>❌ 锯齿严重<br>❌ 信息损失大 |
| **区域平均采样** ✅ | 对10×10区域取平均 | ✅ 保留细节<br>✅ 减少锯齿<br>✅ 信息损失少 | 计算稍慢（可忽略）|

**本项目采用**：区域平均采样

**代码示例**：
```javascript
// 对源图像的每个10×10区域，计算所有像素的平均灰度值
for (let sy = srcYStart; sy < srcYEnd; sy++) {
    for (let sx = srcXStart; sx < srcXEnd; sx++) {
        graySum += getPixelGray(sx, sy);
        count++;
    }
}
avgGray = graySum / count;  // 平均值，而非单点
```

**效果**：8像素宽的线条在缩小后依然清晰可见！
