🧠 知识小课堂

🔍 AI小侦探是谁？

AI小侦探是一个聪明的计算机程序！它会像真正的侦探一样，拿着放大镜仔细观察你的画，寻找能帮助它判断的"线索"。每个线索都是画中的一个特征，比如三角形、圆形或直线。

例如：
  • 🔺 看到尖尖的三角形 → 可能是猫耳朵
  • ⭕ 看到圆形 → 可能是脸或花瓣
  • 📏 看到直线 → 可能是花茎

📋 什么是档案库？

档案库就像一本图鉴，里面记录了不同物体的特征。AI小侦探会把找到的线索和档案库里的记录对比，看看最像哪一个！

小猫档案： 顶部有尖耳朵 + 中间有圆脸
花朵档案： 周围有花瓣 + 下方有花茎

🎒 什么是线索卡片？

AI小侦探找到线索后，会把它们记录在卡片上。每张卡片用不同的颜色表示线索有多明显：红色=很明显，蓝色=不太明显。这些卡片会帮助它做最后的判断！

卡片类型：
◇ 形状卡 | ┃ 竖线卡 | ━ 横线卡

🤖 AI如何学习？

就像你学认字一样，AI也需要练习！在训练模式下，你画一个小猫并告诉它"这是小猫"，它就会记住这个样子。画的例子越多，它就越聪明！

学习过程： 看例子 → 找规律 → 记住特征 → 识别新图片

🎯 为什么要寻找"特征"？

如果直接记住整张图，画法稍微变一点就认不出来了。但如果记住关键特征（耳朵、花瓣等），不管你怎么画，只要这些特征在，AI就能认出来！

比喻： 你认朋友不是靠记住他的衣服，而是记住他的脸、声音等不会变的特征！

🔬 什么是"扫描"？

AI小侦探用放大镜一小块一小块地看你的画，就像你读书时一个字一个字地看。通过扫描每个区域，它能找到藏在画里的所有线索！

扫描步骤： 从左到右 → 从上到下 → 找到所有线索 → 汇总

🌈 颜色的含义

在线索卡片中，不同颜色代表不同的意思。AI用这些颜色快速判断哪些线索最重要！

颜色说明：
• 🔴 红色：非常明显的特征
• 🟡 黄绿色：比较明显的特征
• 🔵 蓝色：不太明显的特征

⚡ 为什么识别这么快？

AI小侦探会把复杂的画简化成几张简单的卡片，这样对比起来非常快！就像你看到一个人，不需要数他有多少根头发，只要看到大概的样子就能认出来。

加速方法： 只记住重要信息 → 忽略细节 → 快速比对

真实的AI系统会寻找更多种类的线索，但核心思想是一样的：寻找特征 → 对比档案 → 得出结论！
